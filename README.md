# NEXUSV-ARCHITECTURAL-SYNTHESIS-AND-VERIFICATION-OF-AN-RV32I-SOC
Nexus-V: A 32-Bit Bus-Interconnect RISC-V (RV32I) SoC PlatformA completely software-verified, highly optimized, synthesizable 32-bit System-on-Chip (SoC) platform built from the ground up using structural Verilog HDL. The entire hardware processing fabric, address decoding matrix, and communication peripherals are integrated and verified inside Xilinx Vivado 2018.3, targeted directly at the Xilinx Artix-7 (XC7A100T-1CSG324C) FPGA silicon footprint.
🛠️ Modular System Architecture & File LayoutTo emulate production-grade industrial computer architectures, the computing fabric is explicitly decoupled into 7 specialized sub-modules. This multi-layered structure prevents the processing pipeline from bottlenecking on slower external execution loops:soc_defs.v (Global Parameter Configuration Hub) – Dictates compile-time hardware boundaries, establishing memory map spacing for a 32KB on-chip memory sector, UART transceivers, and I2C registries.rv32i_core.v (Processing Pipeline Engine) – Implements a 32-bit RISC-V state machine running a multi-cycle execution loop (Fetch, Wait, Execute) supporting RV32I-compliant base integer computational instruction parsing.soc_interconnect.v (Central Bus Matrix Router) – Functions as an AMBA-style address decoder, sampling control signals from the CPU master core and activating individual peripheral select lines (sel_ram, sel_uart, sel_i2c) via valid/ready handshake signals.soc_ram.v (Unified Storage Block) – Implements 32KB of local Block RAM (BRAM) primitive storage using synthesizable byte-lane write strobe masking, pre-programmed with code blocks at startup via $readmemh.soc_uart.v (Baud Rate Transceiver Peripheral) – Contains a hardware serial communication module equipped with an independent internal clock-divider loop calibrated to run a stable 115200 Baud shift-register configuration.soc_i2c.v (Telemetry Master Peripheral) – Emulates a telemetry sensor tracking interface, utilizing explicit Xilinx bidirectional tri-state data buffers (1'bz mapping) to securely prevent signal contention on shared IO buses.nexusv_top.v (Top-Level Structural Integration Wrapper) – Unifies all connective routing paths, hardware submodules, and external pin map references into a single cohesive chip fabric.🔹 Timing, Power, & Thermal Performance (100MHz Continuous Clock Constraint)Design Timing Budget: Closed successfully with 0 Failing Endpoints across 4,173 internal execution paths (Total Negative Slack = 0.000 ns).Total On-Chip Power Draw: 6.202 W (98% Dynamic, 2% Device Static). ⚡ How to Run and Verify the Platform in VivadoClone or download this repository files into your local project workspace.Launch Xilinx Vivado 2018.3 and create an RTL Project targeted at part number xc7a100tcsg324-1.Import files 1 through 7 under the Design Sources category directory.Import tb_nexusv_top.v under the Simulation Sources category directory.Create a plain text file named exactly firmware.hex containing your RISC-V machine opcodes (or use the provided NOP baseline example file) and save it inside your local project directory path: [Project_Name].sim/sim_1/behav/xsim/.Click Run Simulation ➡️ Run Behavioral Simulation inside the left navigator sidebar flow to pull up the timing wave analyzer workspace window. Add pc[31:0] and pipeline_state signals to trace operations.Click Run Synthesis inside your dashboard workflow manager to evaluate gate allocations, cell nets, power characteristics, and the physical RTL Netlist Schematic Layout tree diagram.
